# 💰 Expense Tracker with Alerts

A Java-based console application to manage daily expenses, track category-wise budgets, and generate real-time spending alerts.

Built using core Java concepts, file handling, Java NIO, Streams API, and Object-Oriented Programming principles.

---

# 🚀 Features

✅ Add Expenses  
✅ View All Expenses  
✅ Delete Expenses  
✅ Set Monthly Budget by Category  
✅ Real-Time Budget Alerts  
✅ Monthly Expense Summary  
✅ CSV-Based Persistent Storage  
✅ Automatic Data File Creation  

---

# 🔔 Smart Budget Alert System

The application automatically monitors spending and generates alerts:

- ⚠️ Warning Alert at **80%** budget usage
- 🚨 Exceeded Alert at **100%** budget usage

---

# 🛠️ Tech Stack

- Java 17
- Java NIO
- Java Streams API

- Object-Oriented Programming (OOP)
